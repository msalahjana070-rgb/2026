# IS_16_قسم_الكتاب_المفتوح_القوانين_والثوابت_والمعادلات_علوم_متكاملة.txt

العنوان: ملف 16 - المرجع الشامل للكتاب المفتوح (مادة العلوم المتكاملة - الصف الأول الثانوي 2026-2027)

إعداد: مستر صلاح عيد | تصميم وتطوير المنصة: محمد صلاح

================================================================================

القوانين:

- قانون 1 (الدرس 03 - الكثافة): ρ = m / V، أقصى كثافة للماء النقي = 1 g/cm³ أو 1000 kg/m³ عند 4°C.

- قانون 2 (الدرس 03 - كمية الحرارة): Q = m × c × Δt، الحرارة النوعية للماء النقي c = 4180 J/kg.°C (وفي الدرس 03 مذكورة أيضاً 4200 J/kg·K، ماء مالح 3900، ثلج 2100، بخار ماء 2020، هواء 1005، ألومنيوم 900، نحاس 390، زئبق 140، رصاص 128).

- قانون 3 (الدرس 09 - الضغط المائي والقوة الضاغطة): F = P × A (أو P = F / A)، P_water (atm) = h / 10، P_total (atm) = 1 + (h / 10).

- قانون 4 (الدرس 11 - التروبوسفير): T_h = T_surface - (6.5 × h_km)، تنخفض الحرارة 6.5°C لكل 1 km ارتفاع.

- قانون 5 (الدرس 11 - الاحتفاظ بالغلاف الجوي): V_rms < V_e يحتفظ الكوكب بالغاز (الأرض)، V_rms ≥ V_e يفلت الغاز (عطارد)، سرعة الإفلات للأرض V_e ≈ 11.2 km/s.

- قانون 6 (الدرس 13 - الحرارة): T_K = t_C + 273، t_C = T_K - 273، t_F = (1.8 × t_C) + 32، t_C = (t_F - 32) / 1.8.

- قانون 7 (الدرس 13 - الضغط): 1 atm = 1.013×10⁵ N/m² (Pa) = 760 mmHg = 76 cmHg = 1013 mb، 1 mb = 100 N/m².

الثوابت والأرقام القياسية:

1. نسبة الماء على الأرض: ~70% (97% مياه مالحة | 3% مياه عذبة: 2% متجمدة و 1% عذبة سائلة متاحة).

2. أقصى كثافة للماء النقي: 1 g/cm³ عند 4°C.

3. الضغط الجوي المعتاد عند سطح البحر (0°C): 1 atm = 1.013×10⁵ N/m² = 760 mmHg = 1013 mb.

4. معدل زيادة الضغط المائي: 1 atm لكل 10 m عمق.

5. سرعة الإفلات للأرض: 11.2 km/s.

6. معدل انخفاض الحرارة في التروبوسفير: 6.5°C لكل 1 km.

7. الصفر المطلق: 0 K = -273.16°C = -459.6°F | تجمد الماء: 273 K = 0°C = 32°F | غليان الماء: 373 K = 100°C = 212°F.

8. ضغط الدم الطبيعي للبالغين: 120/80 mmHg.

9. مدى الرطوبة النسبية المريح: 40% - 60%.

10. قوة ارتباط CO بالهيموجلوبين مقارنة بـ O2: 200 - 250 مرة.

11. UV: UVC (100-280 nm)، UVB (280-315 nm)، UVA (315-400 nm)؛ امتصاص N2 و O2 (<240 nm)؛ امتصاص O3 (240-310 nm).

المعادلات الكيميائية الموزونة:

1) تأين الماء النقي (الدرس 02): H2O(l) ⇌ H+(aq) + OH-(aq)

2) ذوبان CO2 وتكون حمض الكربونيك (الدرس 07): CO2(g) + H2O(l) ⇌ H2CO3(aq) ⇌ H+(aq) + HCO3-(aq)

3) تكوين الأوزون في الستراتوسفير (الدرس 12):

   - التفكك الضوئي: O2(g) + UV (< 240 nm) → O(g) + O(g)

   - تكوين الأوزون: O2(g) + O(g) ⇌ O3(g)

4) تكوين حمض الكبريتيك (الدرس 14): 2SO2(g) + O2(g) → 2SO3(g) ثم SO3(g) + H2O(l) → H2SO4(aq)

5) تكوين حمض النيتريك (الدرس 14): 2NO2(g) + H2O(l) → HNO2(aq) + HNO3(aq) أو 4NO2(g) + O2(g) + 2H2O(l) → 4HNO3(aq)

6) تآكل الآثار الجيرية بالأمطار الحمضية (الدرس 14): H2SO4(aq) + CaCO3(s) → CaSO4(s) + CO2(g) + H2O(l)

# IS_02_الخواص_الكيميائية_للماء.txt (الدرس 02 - 1-2)

================================================================================

- جزيء الماء H2O: ذرة أكسجين مرتبطة بذرتي هيدروجين برابطتين تساهميتين أحاديتين بزاوية ~104.5°، ونسبة كتلة H إلى O هي 1:8 (هيدروجين 11.11% وأكسجين 88.89%).

- السالبية الكهربية وقطبية الماء: الأكسجين أعلى سالبية كهربية فيحمل شحنة سالبة جزئية (δ-) والهيدروجين شحنة موجبة جزئية (δ+).

- الرابطة الهيدروجينية: تجاذب كهروستاتيكي بين H(δ+) في جزيء و O(δ-) في جزيء مجاور؛ كل جزيء ماء سائل يكون حتى 4 روابط هيدروجينية، مما يرفع درجة غليان الماء النقي (100°C) مقارنة بـ H2S (-61°C).

- ذوبان NaCl: تفكك لأيونات متهدرتة (Na+ يحاط بالأكسجين δ- و Cl- بالهيدروجين δ+)؛ معادلته: NaCl(s) --(H2O)--> Na+(aq) + Cl-(aq)، ولا يُعد تحللاً مائياً لأن الأيونات لا تتفاعل مع الماء لتكوين أحماض أو قواعد جديدة.

- التحلل المائي للأملاح (التميؤ): NH4Cl محلول حمضي (pH < 7، يزيد [H+])، NaHCO3 محلول قاعدي (pH > 7، يزيد [OH-])، NH4HCO3 محلول متعادل (pH = 7).

- مقياس pH (من 0 إلى 14): الماء المقطر pH = 7، السحب 4.5 - 5، مياه المناجم 3 - 4، ماء البحر 7.5 - 8.4، الأنهار 6.8 - 7.8، البحيرات 7.3 - 8.5، الجوفية 6 - 8.5. يُعاير جهاز pH بالماء المقطر.

# IS_07_تأثير_غازات_الهواء_الجوي_على_البيئات_المائية.txt (الدرس 07 - 1-7)

================================================================================

- مصادر O2: الهواء الجوي (تزيده الأمواج) والبناء الضوئي. مصادر CO2: الغلاف الجوي، تنفس الكائنات البحرية، التلوث الصناعي وتحلل المواد العضوية في الصرف الزراعي. تحصل النباتات والطحالب على CO2 بالانتشار.

- معادلة البناء الضوئي: 6CO2 + 12H2O --(ضوء الشمس / كلوروفيل)--> C6H12O6 + 6H2O + 6O2↑.

- الذوبانية = كتلة الغاز المذاب / حجم المحلول: تركيز O2 في الهواء أعلى بنحو 500 مرة من CO2، لكن ذوبانية O2 في الماء أقل بنحو 50 مرة من CO2، وفي الماء المالح أقل بنحو 20%-30% من العذب، وتقل برفع الحرارة ويتناقص CO2 بمعدل أكبر.

- زيادة CO2 تسبب التحمض (تكوين H2CO3 وخفض pH وضرر البيض واليرقات)، وضعف التنفس، وضعف التكلس بتحويل CaCO3 شحيحة الذوبان إلى Ca(HCO3)2 ذائبة (المرجان من اللاسعات، المحار من الرخويات، قنفذ البحر من شوكيات الجلد، بينما الجمبري من القشريات هيكله من الكيتين، والدعامة الداخلية العظمية من فوسفات الكالسيوم والكولاجين). نقص CO2 يقلل البناء الضوئي والطاقة في سلاسل الغذاء ويرفع pH.

================================================================================

# IS_08_تأثير_الضوء_والإشعاع_الشمسي_على_البيئات_المائية.txt (الدرس 08 - 1-8)

================================================================================

- الطيف الكهرومغناطيسي من الأقصر طولاً موجياً (الأعلى طاقة وتردداً) للأطول: جاما ← السينية ← فوق البنفسجية ← الضوء المرئي (400 nm إلى 700 nm: الأحمر، البرتقالي، الأصفر، الأخضر، الأزرق، النيلي، البنفسجي) ← تحت الحمراء ← الرادار ← الراديو.

- نفاذ الضوء: أكبر ما يمكن عند السقوط العمودي (90°)، يمتص الماء الأشعة تحت الحمراء تقريباً عند 10 cm، وأكثر من 50% من الضوء المرئي عند 10 m، ولا يصل إلى 100 m في المياه الاستوائية الصافية سوى ~1% (معظمه أزرق). المنطقة المضاءة حتى ~200 m، تليها الشفقية ثم المظلمة/العميقة.

- الشعاب المرجانية تزدهر قرب خط الاستواء بفضل طحالب تكافلية؛ التونة والباراكودا في المياه الدافئة والقد (Cod) في الباردة؛ تيار الخليج (Gulf Stream) يدفئ شمال الأطلسي ويعتدل مناخ أوروبا الغربية؛ في المياه العكرة تنمو الطحالب أقرب للسطح.

================================================================================

# IS_09_تأثير_الضغط_المائي_على_الكائنات_الحية.txt (الدرس 09 - 1-9)

================================================================================

- الموائع (سوائل وغازات): الغازات قابلة للانضغاط بشدة، والسوائل تقاوم الانضغاط وتحتفظ بحجم ثابت تقريباً.

- F = P × A، الضغط بالباسكال (Pa = N/m²)، الضغط الجوي القياسي 1 atm = 1.013×10⁵ N/m²، يزيد ضغط الماء ~1 atm لكل 10 m عمق، P_total (atm) = 1 + (h/10). عند نفس العمق ضغط الماء المالح أكبر من العذب.

- المثانة الهوائية: تتحكم في الطفو في الأعماق المتوسطة (200-1000 m كالسلمون)، وقد تتمدد وتنفجر إذا صعدت السمكة بسرعة للسطح. في الأعماق السحيقة (>2000 m) قد تنعدم المثانة الغازية (كالراي) أو يوجد كبد غني بالزيوت للطفو، وتزيد الأحماض الدهنية غير المشبعة والـ Lipoproteins للحفاظ على سيولة ومرونة الأغشية الخلوية. الأسماك العظمية (بلطي، بوري) مقابل الغضروفية (قرش، راي).

# IS_11_مكونات_وطبقات_الغلاف_الجوي.txt (الدرس 11 - 2-1)

================================================================================

- مكونات الغلاف الجوي: النيتروجين N2 (~78% وله رابطة ثلاثية قوية N≡N لذا هو خامل نسبياً)، الأكسجين O2 (~21%)، الأرجون Ar (~0.93%)، ثاني أكسيد الكربون CO2 (~0.04% غاز دفيء)، وغازات أخرى.

- الطبقات الخمس: (1) التروبوسفير (0-10 km، الطقس والمناخ، تنخفض الحرارة 6.5°C/km، تروبوبوز ~11 km) (2) الستراتوسفير (10-50 km، طيران أفقي، أوزون 20-40 km يرفع الحرارة) (3) الميزوسفير (50-80 km، أبرد طبقة -93°C وتحترق فيها الشهب) (4) الثرموسفير (80-700 km، >2000°C، أيونوسفير 80-550 km يعكس الراديو ويحدث به الشفق القطبي) (5) الأكسوسفير (700-1000 km، شبه فراغ وأقمار GPS).

- سرعة الإفلات للأرض V_e ≈ 11.2 km/s: يحتفظ الكوكب بالغاز إذا V_rms < V_e (الأرض) ويفلت إذا V_rms ≥ V_e (عطارد).

# IS_12_التفاعلات_الكيميائية_في_الغلاف_الجوي.txt (الدرس 12 - 2-2)

================================================================================

- الأشعة فوق البنفسجية: UVC (100-280 nm الأعلى طاقة)، UVB (280-315 nm)، UVA (315-400 nm الأطول موجياً). استخداماتها: تعقيم المعدات الجراحية وكشف الأوراق النقدية المزيفة.

- امتصاص N2 و O2 (<240 nm) و O3 (240-310 nm). خطوتا تكوين الأوزون: O2(g) + UV (<240 nm) → O(g) + O(g) ثم O2(g) + O(g) ⇌ O3(g).

- تآكل الأوزون بسبب CFCs (التبريد والتكييف والإيروسولات) والهالون (طفايات الحريق). أضرار UV: سرطان الجلد (الميلانوما Melanoma وتلف DNA)، ضعف المناعة (تثبيط الخلايا التائية المساعدة Helper T-cells)، والمياه البيضاء (Cataract).

- اكتشاف ثقب الأوزون 1985 فوق أنتاركتيكا، وبروتوكول مونتريال 1987، وغاز التبريد الآمن 410A، والخل وصودا الخبز.

- الأوزون الأرضي الضار في التروبوسفير: ينتج من تفاعل أكاسيد النيتروجين مع الهيدروكربونات في ضوء الشمس، ويسبب الضباب الدخاني (Smog) مع SO2 و NO2 والجسيمات، واحتراق أوراق النباتات، وتآكل البلاستيك والمطاط، وأمراض الجهاز التنفسي والحساسية والتهاب الشعب الهوائية.

    function parseLessons(text) {

      const sections = text.split(/^#+\s*/m).filter(Boolean);

      const lessons = [];

      for (const sec of sections) {

        const lines = sec.split('

    function normalizeArabic(str = '') {

      return str

        .toLowerCase()

        .replace(/[إأآا]/g, 'ا')

        .replace(/ة/g, 'ه')

        .replace(/ى/g, 'ي')

        .replace(/[ً-ٰٟ]/g, '')

        .replace(/[^ء-يa-z0-9\s]/g, ' ')

        .replace(/\s+/g, ' ')

        .trim();

    }

    function retrieveRelevantContext(query, lessonFilter = '') {

      const fullText = getCurriculumText();

      const lessons = parseLessons(fullText);

      const poolText = lessonFilter

        ? (lessons.find(l => l.title === lessonFilter)?.content || fullText)

        : fullText;

      const chunks = poolText

        .split(/

{2,}|={20,}|-{20,}/)

        .map(c => c.trim())

        .filter(c => c.length > 20);

      const qNorm = normalizeArabic(query);

      const words = qNorm.split(' ').filter(w => w.length > 1);

      const scored = chunks.map(chunk => {

        const cNorm = normalizeArabic(chunk);

        let score = 0;

        for (const w of words) {

          if (cNorm.includes(w)) score += 2;

        }

        if (qNorm.length > 3 && cNorm.includes(qNorm)) score += 5;

        return { chunk, score };

      });

      scored.sort((a, b) => b.score - a.score);

      const matched = scored.filter(item => item.score > 0).slice(0, 4).map(item => item.chunk);

      return matched.length ? matched.join('

---

') : chunks.slice(0, 3).join('

---

');

    }

    function formatRichText(rawText) {

        .replace(/</g, '&lt;')

      html = html.replace(/\$\$([\s\S]+?)\$\$/g, (_, expr) => {

        const cleanExpr = expr.replace(/&amp;/g, '&').replace(/&lt;/g, '<').replace(/&gt;/g, '>').trim();

        if (window.katex) {

          try {

            return window.katex.renderToString(cleanExpr, { displayMode: true, throwOnError: false });

          } catch (_) {}

        }

        return `<div class="katex-display">${cleanExpr}</div>`;

      });

      // Inline math $...$

      html = html.replace(/\$([^\$

]+?)\$/g, (_, expr) => {

        const cleanExpr = expr.replace(/&amp;/g, '&').replace(/&lt;/g, '<').replace(/&gt;/g, '>').trim();

        if (window.katex) {

          try {

            return window.katex.renderToString(cleanExpr, { displayMode: false, throwOnError: false });

          } catch (_) {}

        }

        return `<span class="katex">${cleanExpr}</span>`;

      });

      // Bold **...**

      html = html.replace(/\*\*([^*]+)\*\*/g, '<strong class="text-emerald-300">$1</strong>');

      html = html.replace(/

/g, '<br />');

      return html;

    }
